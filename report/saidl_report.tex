\begin{abstract}
Long-context modeling is a foundational challenge in modern Deep Learning. Standard self-attention has a quadratic compute and memory complexity, $O(T^2)$, and vanilla position encodings fail to generalize to longer contexts at inference time. This report documents the implementation and systematic empirical study of various attention mechanisms, positional encodings, and hybrid architectures on the WikiText-2 next-token prediction task.
\end{abstract}

\section{CORE ML TASK}

\subsection{Introduction}
We design and evaluate a modular sequence model using a pre-LayerNorm Transformer backbone. The architecture is engineered to dynamically swap attention layers, positional encodings, and convolutional hybrid stages. All models are trained local-first on a consumer hardware setup (NVIDIA RTX 4050, 6GB VRAM) under tight memory constraints.

\subsection{Experimental Setup}
The experiments are conducted on the WikiText-2 dataset. For the core machine learning tasks, the models are trained with a sequence length of 512, an embedding dimension of 256, 4 attention heads, and 4 layers. The batch size is fixed to 16, and the models are trained for 10 epochs using the Adam optimizer with a learning rate of $5 \times 10^{-4}$. We implement weight tying between the token embedding and the language modeling head. The training hardware is an NVIDIA RTX 4050 GPU (6GB VRAM). For the diffusion tasks, we utilize the \texttt{stabilityai/sd-vae-ft-mse} autoencoder and a DiT-B/2 model trained on a landscape dataset with a batch size of 8.

\subsection{Theoretical Analysis of Positional Encodings}

\subsubsection{Sinusoidal Positional Encoding (Baseline)}
The standard sinusoidal positional encoding assigns a static, absolute positional vector to each input token. For position $p \in \{0, \dots, T-1\}$ and channel index $i \in \{0, \dots, d/2 - 1\}$, the coordinates are:
\begin{align}
    PE(p, 2i) &= \sin\left(\frac{p}{10000^{2i/d}}\right) \\
    PE(p, 2i+1) &= \cos\left(\frac{p}{10000^{2i/d}}\right)
\end{align}
These vectors are added directly to the input word representation:
\begin{equation}
    \mathbf{x}_p \leftarrow \mathbf{x}_p + PE(p)
\end{equation}
Because the vectors represent absolute coordinates, the attention layers must learn query-key combinations that represent relative distances, which does not generalize well to unseen context lengths.

\subsubsection{Rotary Positional Embedding (RoPE)}
Rotary Positional Embedding (RoPE) resolves this by applying a position-dependent rotation to the Query ($\mathbf{q}$) and Key ($\mathbf{k}$) vectors in the 2D complex plane. 

Given a $d$-dimensional query vector $\mathbf{q}_m$ at sequence position $m$, we divide it into $d/2$ pairs of adjacent elements:
\begin{equation}
    \mathbf{q}_m = [q_{m,1}, q_{m,2}, q_{m,3}, q_{m,4}, \dots, q_{m,d-1}, q_{m,d}]^T
\end{equation}
For each pair $(q_{m,2i-1}, q_{m,2i})$, we rotate it by an angle $m\theta_i$:
\begin{equation}
    \begin{pmatrix} \tilde{q}_{m,2i-1} \\ \tilde{q}_{m,2i} \end{pmatrix} = 
    \begin{pmatrix} \cos(m\theta_i) & -\sin(m\theta_i) \\ \sin(m\theta_i) & \cos(m\theta_i) \end{pmatrix}
    \begin{pmatrix} q_{m,2i-1} \\ q_{m,2i} \end{pmatrix}
\end{equation}
where the scale factor for the frequency is:
\begin{equation}
    \theta_i = 10000^{-2(i-1)/d}, \quad i \in \left\{1, \dots, \frac{d}{2}\right\}
\end{equation}
In matrix form, this is represented as a block-diagonal rotation matrix $\mathbf{R}_{\Theta, m}^d$:
\begin{equation}
    \tilde{\mathbf{q}}_m = \mathbf{R}_{\Theta, m}^d \mathbf{q}_m, \quad \tilde{\mathbf{k}}_n = \mathbf{R}_{\Theta, n}^d \mathbf{k}_n
\end{equation}
Taking the inner product of the rotated queries and keys yields:
\begin{equation}
    \langle \tilde{\mathbf{q}}_m, \tilde{\mathbf{k}}_n \rangle = \mathbf{q}_m^T \left(\mathbf{R}_{\Theta, m}^d\right)^T \mathbf{R}_{\Theta, n}^d \mathbf{k}_n = \mathbf{q}_m^T \mathbf{R}_{\Theta, n-m}^d \mathbf{k}_n
\end{equation}
This mathematically guarantees that the self-attention score between position $m$ and position $n$ is a **pure function of their relative distance $n-m$**, enabling smooth length extrapolation.

\subsubsection{ALiBi (Attention with Linear Biases)}
ALiBi removes positional embeddings entirely. Instead, it injects a static, non-learned bias directly into the attention matrix, penalizing distant query-key pairs linearly:
\begin{equation}
    \text{Attention}(Q, K) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}} - m \cdot \mathbf{B}\right)
\end{equation}
where $\mathbf{B}$ is a matrix representing relative distance ($B_{i,j} = i - j$ for causal attention), and $m$ is a head-specific slope scalar.

\subsubsection{Relative Positional Encoding (Shaw et al.)}
Relative Positional Encoding explicitly parameterizes the relative distance $i - j$ as a learnable vector $\mathbf{w}_{i-j}^K$ inside the self-attention formulation. To constrain the number of learned parameters, the relative distance is clipped to a maximum distance $k$:
\begin{equation}
    \text{clip}(x, k) = \max(-k, \min(k, x))
\end{equation}
The attention score $e_{ij}$ between a query at position $i$ and key at position $j$ is computed as:
\begin{equation}
    e_{ij} = \frac{\mathbf{q}_i \mathbf{k}_j^T + \mathbf{q}_i (\mathbf{w}_{\text{clip}(i-j, k)}^K)^T}{\sqrt{d_k}}
\end{equation}
This approach fundamentally shifts the model from relying on absolute token locations to focusing entirely on the relative distance between interacting tokens, offering natural generalization to longer sequence lengths.

\subsection{Theoretical Analysis of Attention Variants}

To further optimize the memory bottleneck and computational complexity of standard $O(T^2)$ attention, we implemented and evaluated three modern attention variants:

\subsubsection{Multi-Query Attention (MQA)}
Standard Multi-Head Attention projects the input into $H$ distinct query, key, and value vectors. In contrast, Multi-Query Attention (MQA) shares a single key and value projection across all $H$ query heads.
\begin{equation}
    \text{MQA}(x) = \text{Concat}(\text{head}_1, \dots, \text{head}_H)W^O
\end{equation}
where $\text{head}_i = \text{Attention}(xW_i^Q, xW^K, xW^V)$. This drastically reduces the memory bandwidth required to load keys and values during generation, speeding up inference without significantly degrading model quality.

\subsubsection{Sliding Window Attention}
Natural language exhibits strong local locality. Sliding Window Attention exploits this by restricting each token's receptive field to a fixed window $W$ of previous tokens. The modified attention mask $M \in \mathbb{R}^{T \times T}$ is defined as:
\begin{equation}
    M_{i,j} = 
    \begin{cases} 
      1 & \text{if } 0 \le i - j < W \\
      0 & \text{otherwise}
    \end{cases}
\end{equation}
By computing sparse attention over this diagonal band, the computational complexity is reduced from $O(T^2)$ to $O(T \times W)$, enabling the model to process much longer documents while retaining local context.

\begin{lstlisting}[language=Python, caption=Exact causal masking in Sliding Window Attention.]
# Causal mask logic implemented in core_ml/attention.py
causal = torch.tril(torch.ones(T, T, dtype=torch.bool, device=x.device))
window = torch.triu(torch.ones(T, T, dtype=torch.bool, device=x.device), diagonal=-(self.window_size - 1))
sw_mask = causal & window
\end{lstlisting}

\subsubsection{Linear Attention (Causal)}
Standard attention computes $(Q K^T) V$. Linear Attention circumvents the $O(T^2)$ $Q K^T$ matrix multiplication by applying a non-negative feature map $\phi(x) = \text{elu}(x) + 1$ to the queries and keys, and exploiting matrix associativity: $\phi(Q) (\phi(K)^T V)$.
For causal sequence modeling, the $i$-th output row is computed iteratively using running sums:
\begin{equation}
    V_i = \frac{\phi(q_i)^T \sum_{j=1}^i \phi(k_j) v_j^T}{\phi(q_i)^T \sum_{j=1}^i \phi(k_j)}
\end{equation}
By maintaining a cumulative sum (via \texttt{torch.cumsum}) of the $d \times d$ matrix $\phi(k_j) v_j^T$ and the vector $\phi(k_j)$, we compute exact causal attention in $O(T \cdot d^2)$ time, achieving strictly linear scaling with respect to sequence length.

\subsection{Convolution + Attention Hybrid Architectures}

Pure attention models struggle to efficiently encode strong local patterns. Convolutional layers are naturally suited for local n-gram modeling (via weight-sharing over a sliding kernel window), while attention excels at global context. We implement two hybrid designs that combine both inductive biases.

\subsubsection{Design 1: Conv1D Before Attention (\texttt{conv\_before})}
A causal 1D convolution is inserted as an additional sub-layer before each standard attention block. For a causal kernel of size $K$ applied to input $x \in \mathbb{R}^{T \times d}$, the output at position $t$ depends only on positions $\{t-K+1, \ldots, t\}$:
\begin{equation}
    \text{ConvOut}_t = \sum_{k=0}^{K-1} W_k \cdot x_{t-k}, \quad W_k \in \mathbb{R}^{d \times d}
\end{equation}
Causality is enforced via left-padding of $(K-1)$ zeros before the convolution, requiring no masking. The modified block becomes:
\begin{align}
    x &\leftarrow x + \sigma(\text{CausalConv1d}(\text{LN}(x))) \cdot W_{\text{proj}} \\
    x &\leftarrow x + \text{Attention}(\text{LN}(x)) \\
    x &\leftarrow x + \text{FFN}(\text{LN}(x))
\end{align}
With kernel size $K=7$, this efficiently captures 7-gram local context for free (no extra quadratic cost), complementing the global attention.

\subsubsection{Design 2: Gated Depthwise Conv FFN (\texttt{gated\_conv\_ffn})}
Inspired by the Conformer architecture, the standard MLP feedforward sub-layer is replaced with a Gated Convolutional FFN using Gated Linear Units (GLU) and depthwise-separable convolutions:
\begin{align}
    h &= \text{Linear}_{\text{up}}(\text{LN}(x)) \in \mathbb{R}^{T \times 2h} \\
    v, g &= \text{split}(h) \in \mathbb{R}^{T \times h} \quad \text{(value and gate)} \\
    h' &= v \odot \sigma(g) \quad \text{(gated linear unit)} \\
    x &\leftarrow x + W_{\text{down}}(\text{DepthwiseConv1d}(h'))
\end{align}
The depthwise convolution (kernel size $K=31$) applies a \emph{per-channel} causal convolution, providing local positional context without the $O(d^2)$ cost of a pointwise convolution. This replaces a 2-layer MLP with a compute-efficient local mixing operation that is sensitive to token order.

\section{DOMAIN TASK RACD}

While the core Transformer scales excellently on discrete tokens, the Diffusion Transformer (DiT) extends this paradigm to continuous visual latent spaces. Our implementation replaces the U-Net with a DiT-B/8 architecture operating on $32 \times 32 \times 4$ latents encoded by a frozen VAE. 

\subsection{Global Cyclic Refinement}
Cyclic refinement improves generation quality by performing a "polishing" pass. After generating the initial clean latent $x_0$, we re-inject noise up to $t=200$:
\begin{equation}
    x_{200} = \sqrt{\bar{\alpha}_{200}} x_0 + \sqrt{1 - \bar{\alpha}_{200}} \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)
\end{equation}
We then denoise $x_{200}$ back to $x_0$. While this reduces residual errors, it uniformly increases compute by 20\%, even on simple background patches (e.g., sky) that require no refinement.

\subsection{Difficulty Predictor & RACD}
To optimize this trade-off, we implement Regionally-Adaptive Cyclic Diffusion (RACD). We define a lightweight Convolutional Difficulty Predictor $P_\phi$ that operates on intermediate DiT features $h_t$:
\begin{equation}
    M = \sigma(P_\phi(h_t)) \in [0, 1]^{16 \times 16}
\end{equation}
The predictor is supervised by comparing an intermediate prediction of $x_0$ against the ground-truth $x_0$, forming a patch-wise MSE error mask. During inference, noise re-injection is strictly applied to patches where $M_{ij} > \tau$. 

\begin{lstlisting}[language=Python, caption=RACD dynamic difficulty masking.]
# Re-injection masking logic implemented in diffusion/racd.py
difficulty_mask = torch.sigmoid(predictor(h)) # h is DiT features
mask_bool = difficulty_mask > tau
x_t = torch.where(mask_bool, x_noisy, x_clean)
\end{lstlisting}

\subsection{Analysis of RACD Hardware Overhead}
While RACD theoretically reduces the number of denoising FLOPs by selectively targeting patches, our empirical results show a \textbf{659.7\% increase} in wall-clock compute time (11.744s vs 1.546s per image). This is a classic example of \textbf{CUDA synchronization overhead}. 

Evaluating the conditional mask $M_{ij} > \tau$ and dynamically selecting spatial indices forces the GPU to constantly synchronize with the CPU to determine control flow during every timestep of the diffusion loop. In a naive PyTorch implementation without fused custom CUDA kernels (e.g., Triton or CUDA C++), this GPU-CPU blocking completely destroys tensor parallelism. Thus, while mathematically elegant, dynamic spatial sparsity requires specialized low-level hardware optimizations to yield actual wall-clock speedups.

\section{CONCLUSION \& FUTURE WORK}
In this assignment, we explored various architectural modifications to the Transformer to handle long-context sequence modeling efficiently. We demonstrated that relative positional encodings like ALiBi and RoPE significantly outperform absolute encodings in extrapolation. Furthermore, we showed that attention variants like Linear Attention and MQA provide substantial throughput improvements. Finally, we explored Regionally-Adaptive Cyclic Diffusion (RACD) for efficient image generation, analyzing the theoretical benefits against the empirical CUDA synchronization overhead. Future work involves implementing fused CUDA kernels for RACD to realize the theoretical speedups in practice.
